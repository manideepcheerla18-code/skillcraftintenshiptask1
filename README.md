# 🌡️ TempX - Temperature Converter

TempX is a modern, colorful **Python desktop temperature converter** built with **Tkinter**. It provides a simple app-style interface for converting temperatures between **Celsius, Fahrenheit, and Kelvin**.

## ✨ Features

* 🌡️ Modern and colorful user interface
* 🔄 Quick unit swap functionality
* 🌡️ Celsius, Fahrenheit, and Kelvin conversions
* ⌨️ Laptop keyboard input support
* ⏎ Press **Enter** to convert
* 🧹 Clear input button
* ⌫ Delete/backspace functionality
* 📱 App-style desktop interface
* 🖥️ Maximized window support
* ⚡ Instant conversion results
* 🚫 No external Python packages required

## 🔢 Supported Conversions

* Celsius → Fahrenheit
* Celsius → Kelvin
* Fahrenheit → Celsius
* Fahrenheit → Kelvin
* Kelvin → Celsius
* Kelvin → Fahrenheit

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **ttk**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project

```bash
cd temperature-converter
```

### 3. Run the application

```bash
python temperature_converter.py
```

The TempX application will open directly as a desktop interface.

## 💻 Usage

1. Enter a temperature using your laptop keyboard.
2. Select the **From** unit.
3. Select the **To** unit.
4. Click **CONVERT** or press **Enter**.
5. The converted temperature will appear in the result card.
6. Use **⇄** to quickly swap the units.

## 📌 Example

```text
Input: 25
From: Celsius
To: Fahrenheit

Result: 25 °C = 77.00 °F
```
